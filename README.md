## Используемые технологии
HTML5, CSS3 (переменные, Flexbox, Grid, sticky/fixed), минимальный JavaScript для `<dialog>`, Git, GitHub Pages. Без CSS-фреймворков.

## Как проверить проект
1. Главная → «Каталог», «Товар», «Заявка», «Контакты» — все пять страниц открываются из меню в шапке.
2. Якорные ссылки: `index.html#advantages`, `index.html#popular`, `index.html#contacts` (меню в шапке и в подвале); целевой раздел подсвечивается через `:target`.
3. Кнопка «Заказать» в карточке открывает модальное окно, выбранный товар попадает в заявку; окно закрывается кнопкой, `Esc` и кликом по фону.
4. Форма в модальном окне: пустые обязательные поля подсвечиваются, при корректных данных показывается сообщение об успешной отправке. Формы на `order.html` и `contacts.html` проверяются средствами браузера (`required`, `type="email"`); полноценная JS-валидация — в КР №4.
5. Клавиша `Tab` показывает видимый фокус на ссылках, кнопках и полях.

## Самостоятельные доработки
- собственная тематика магазина, SVG-иллюстрации товаров;
- бейджи «Хит», «Новинка», «Скидка» и модификатор `product-card--discount`;
- блок фильтров каталога (sticky) и хлебные крошки на внутренних страницах;
- две таблицы на странице товара и блок FAQ на `<details>`;
- кнопка «Наверх» и ссылка «Перейти к содержимому» (skip-link);
- доступность: видимый фокус, связанные label/id, `aria-current`, `aria-invalid`, `role="status"`;
- подсветка цели якоря через `:target`, Open Graph-разметка и `sitemap.xml` (дополнительные задания ПР5);
- навигация в подвале с якорными ссылками (`site-footer__nav`);
- модальное окно закрывается по кнопке, `Esc` и клику по фону; в нём показывается выбранный товар.

## Использование Flexbox и Grid

- `site-nav__list` — `display: flex` с `justify-content`, `align-items`, `gap`;
- `product-card` — `display: flex; flex-direction: column`, блок кнопок прижат к низу карточки;
- `products-grid` — `display: grid` с `repeat(auto-fill, minmax(260px, 1fr))` и `gap`;
- `catalog-layout` — `display: grid`, `grid-template-columns: 260px 1fr`, `grid-template-areas: "filters products"`; `catalog-filters` и `catalog-products` занимают свои области через `grid-area`;
- `catalog-filters__form` — `display: grid` для групп полей фильтра;
- `order-form`, `order-form__actions`, `hero__actions` — Flexbox.

## БЭМ-структура проекта

Блоки (элементы — `block__element`, модификаторы — `block--modifier`):

- `site-header` — шапка сайта (`__inner`, `__logo`);
- `site-nav` — основная навигация (`__list`, `__item`, `__link`, `__link--active`);
- `breadcrumbs` — хлебные крошки (`__list`, `__item`, `__link`, `__current`);
- `hero` — первый экран главной страницы;
- `section`, `advantages`, `note` — разделы и информационные блоки;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (`__image`, `__title`, `__description`, `__price`, `__actions`, `__button`; модификаторы `--featured`, `--discount`);
- `badge` — бейдж (`--hit`, `--new`, `--sale`);
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога (`__form`, `__group`, `__legend`, `__list`, `__item`, `__label`, `__input`);
- `catalog-products` — область списка товаров;
- `product-page`, `spec-table`, `faq` — страница товара, таблицы, FAQ;
- `order-dialog` — модальное окно заявки (`__title`);
- `order-form` — форма заявки (`__field`, `__label`, `__input`, `__select`, `__textarea`, `__actions`, `__actions--start`);
- `button` — кнопка (`--primary`, `--secondary`, `--disabled`);
- `success-message`, `to-top`, `skip-link` — вспомогательные компоненты;
- `site-footer` — подвал сайта.

Стилизация через `id` и inline-стили не используются; `id` оставлены только для якорей, `label for` и JavaScript.

## Дополнительные доработки (сверх методических указаний)

1. **Страница категории `category.html`.** Три модели клавиатур (K1, K2, K3), хлебные крошки третьего уровня, блок «Как выбрать клавиатуру». В каталог добавлены две новые модели с SVG-изображениями, из карточек и подборки в каталоге есть ссылки на категорию. Карточки переиспользуют готовые блоки `products-grid` и `product-card`.
2. **Блок отзывов на `product.html`.** Новые БЭМ-блоки `reviews`, `review-card` (модификатор `--top` — выделенный отзыв) и `rating`: звёзды рисуются CSS-градиентом по значению `--rating-value`, модификаторы `rating--5`, `rating--4`, `rating--4-7`. Разметка семантична: `article`, `header`, `footer`, `time`; у оценки есть текстовая подпись для скринридеров. Отзывы вымышлены, это отмечено на странице.
3. **Таблица сравнения моделей.** `spec-table--compare` на `category.html`: `caption`, `thead`, `tbody`, `tfoot`, `th scope`, ячейки с лучшими значениями (`spec-table__cell--best` + текстовая метка, чтобы смысл не зависел от цвета), закреплённый первый столбец (`sticky`), горизонтальная прокрутка внутри `table-wrap` на узких экранах, кнопки заказа в `tfoot`.
4. **Собственная визуальная концепция «графит + индиго + янтарь».** Тёмные шапка, hero и подвал, светлый контент, янтарный акцент. Всё задаётся CSS-переменными в `:root` (`--color-primary`, `--color-accent`, `--color-surface-dark`, `--color-on-dark`, `--font-heading` и др.). Добавлены варианты кнопки `button--accent`, `button--light`, `button--small`. Контраст текста проверен (не ниже 4.5:1), на тёмном фоне фокус виден янтарным контуром.

Кнопки заказа в `js/main.js` теперь находятся по атрибуту `data-product`, а не по классу `product-card__button`: так модальное окно открывается и из таблицы сравнения, и из карточек.
